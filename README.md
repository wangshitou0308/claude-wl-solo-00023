# 刻度回找 — 老收音机找台助手

面向仍用指针式收音机收听地方台、戏曲、短波节目的中老年人。解决两个老问题：

1. **刻度稀疏**：记下频率（如 9.27 MHz）也对不准指针位置；
2. **旋钮回程间隙（背隙）**：从低端拧到和从高端拧到，指针停的位置不一样，记下频率仍找不回原台。

照片与全部记录只保存在本机浏览器（IndexedDB），不上传、不联网。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173/ ），建议用手机/平板在收音机旁横屏使用。
生产构建：`npm run build`，预览构建产物：`npm run preview`。

## 使用流程

### 1. 添加收音机
首页点「＋ 添加收音机」，填机器称呼（如「红灯 753」），拍/选一张正对刻度盘的清晰照片，
按波段开关添加波段（FM / MW / 短波米波段，可自定义单位与范围）。

### 2. 按方向分别标定（每个方向至少 3 个点）
在「① 标定刻度」页先选方向：

- **↑ 从低端接近**：旋钮只沿频率增大方向，缓慢拧到已知频率/电台后停住；
- **↓ 从高端接近**：旋钮只沿频率减小方向拧到同一些频率。

在照片上点指针所在的刻度位置，填写：

- 频率读数；
- **位置误差**：停准时指针可能偏差多少（拖滑块调误差圈，越有把握圈越小）；
- **台呼**（中国之声、地方戏曲广播…）与**节目声线索**（报时、开始曲、锣鼓点、主持人声…）。

点可点选后直接在照片上拖动修正，也可「改 / 删」。每次新增、修改、删除都可在底部提示条**撤销**。

正、反方向数据始终分成两条独立分段校准，**绝不混算**；也可勾选「淡显另一方向对照」（仅显示，不参与计算）。

### 3. 生成找台卡
在「② 找回电台」页填目标频率、最终接近方向与确认线索。标定不足 3 点、走向不单调
（频率增大但刻度位置回退）或同频两点矛盾时，会保留候选并明确指出冲突，不出卡。

卡片先根据目标频率沿标定折线算出**可能位置区间**（绿色宽带，半宽由位置误差、分段残差、
读数误差合成，标区外自动加宽），再给出 5 屏逐步操作：

1. **准备**：可选点出指针当前位置，判断在目标哪一侧；
2. **先越过**：朝错误方向拧过目标，停到区间外侧的橙色小旗（自动加上本机回程间隙估计 + 安全余量）；
3. **回拧进入**：只沿指定方向慢速单向拧入绿区到红十字，中途绝不回头；
4. **停住辨听**：屏幕只显示这一屏该做的动作和台呼/节目声确认线索，可报「没听到」重试或「拧过头重走」；
5. **完成**：可打印三步示意图卡，拿到收音机旁照着做。

回程间隙由正反两向成对频率点的位置间距自动估算（中位数）。

### 4. 自动作废、续做与打印
- 标定点一旦增删改，相关波段的旧卡**立即标记为已作废**（版本哈希比对），可查看、按新标定重建或删除；
- 找台进度停在第几步都存在浏览器里，**刷新/关闭后可继续**；
- 「打印逐步卡」把第 1 拧、第 2 拧、辨听三张示意图与确认线索输出为可打印页。

## 实现要点

- React 18 + TypeScript + Vite；
- Canvas API：照片叠加层（点/误差圈、分段折线、目标区间、越台小旗、当前指针）同一套绘制逻辑
  复用于交互画布与离屏打印快照（`src/lib/draw.ts`）；
- 校准数学（`src/lib/calibration.ts`）：按「波段 × 方向」分组，沿相邻点弦长轴做分段线性插值，
  单调冲突用段间有符号投影检测；区间半宽合成端点误差传播、留一法残差与读数误差；
- IndexedDB（`src/lib/db.ts`，无第三方库）：`radios`（照片存 Blob）、`points`、`findings`、`undo` 四个对象仓。
